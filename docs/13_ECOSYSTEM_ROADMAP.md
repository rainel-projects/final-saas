# Long-Term Ecosystem Roadmap

## Vision
Nexus becomes the "Operating System" for the decentralized web.

## Extensions & Plugins
-   **Identity Providers**: Plugins for Google Auth, GitHub Auth, Ethereum Wallet, Solana Wallet.
-   **Storage Backends**: Plugins for S3 (hybrid), Dropbox, Google Drive.
-   **Databases**: Plugins for SQL (SQLite over P2P), Graph DBs.

## SDK Expansion
-   **Mobile**: Native iOS/Android SDKs.
-   **IoT**: Rust SDK for embedded devices (Raspberry Pi nodes).
-   **Gaming**: Unity/Unreal Engine plugins for P2P multiplayer state.

## The "App Store"
-   A decentralized registry of "Nexus Modules".
-   Developers publish modules (e.g., "P2P Video Chat Module").
-   Other devs buy/rent them.
-   Protocol takes a cut.
