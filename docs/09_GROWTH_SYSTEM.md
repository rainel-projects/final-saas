# Zero-Cost Growth System

## Strategy: "Viral Utility"
We don't buy ads. We build tools that developers *have* to share because they solve a burning pain.

## Tactics

### 1. The "Trojan Horse" Open Source Tools
-   Build tiny, useful CLI tools using Nexus under the hood (e.g., a "P2P File Transfer" CLI like `wormhole`).
-   Distribute them on npm/brew.
-   Users install for the utility, but they become nodes in the network.

### 2. "Powered by Nexus" Badge
-   Free tier users (using the managed gateway) must display a "Powered by Nexus" badge.
-   Clicking it leads to the "Build your own" page.

### 3. Content Engineering
-   Write high-quality technical articles: "How we built a serverless DB in 100 lines of JS".
-   Post on Dev.to, Hashnode, Hacker News.
-   **No marketing fluff.** Pure engineering value.

### 4. Incentivized Referrals
-   "Invite a friend, get 1GB of premium storage."
-   Affiliate system built into the protocol: Referrers get 1% of the fees generated by their referrals forever.

## The Flywheel
1.  Dev builds app on Nexus.
2.  Users use app -> become nodes.
3.  Network capacity grows -> Performance improves.
4.  More devs join because performance is good.
