# 180-Day Scaling Roadmap: The Ecosystem

## Goal
Reach 1,000 active nodes and first revenue through automated protocol fees.

## Month 3-4: The Marketplace & Compute
-   **Compute Nodes**: Allow users to run a Node.js CLI that listens for "jobs" (e.g., resize image, generate thumbnail).
-   **Marketplace UI**: A registry of available compute nodes and their prices.
-   **Payment Channels**: Implement simple state channels for micro-payments (Testnet tokens initially).

## Month 5-6: Automation & Revenue
-   **Mainnet Payments**: Integrate stablecoin payments (USDC/DAI) on L2 (Polygon/Arbitrum).
-   **Automated Billing**: Protocol takes a cut of every compute task.
-   **Governance Lite**: Token holders can vote on protocol parameters (fees, featured nodes).

## Metrics to Watch
-   **Daily Active Nodes (DAN)**.
-   **Data Stored (GB)**.
-   **Compute Tasks Executed**.
