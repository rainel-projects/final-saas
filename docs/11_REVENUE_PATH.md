# Revenue Path to ₹1,00,00,000 (~$120k)

## Milestone 1: ₹0 -> ₹1,00,000 ($1.2k)
-   **Focus**: Validation & Early Adopters.
-   **Product**: MVP (Storage + Auth).
-   **Source**: 
    -   10 "Patron" users paying $100/lifetime for early access.
    -   Donations/Grants (Gitcoin).

## Milestone 2: ₹1,00,000 -> ₹10,00,000 ($12k)
-   **Focus**: Developer Traction.
-   **Product**: Compute Marketplace Live.
-   **Source**:
    -   100 Active Apps paying avg $10/mo (fees).
    -   Enterprise "Self-Hosted" Licenses (5 licenses @ $2k each).

## Milestone 3: ₹10,00,000 -> ₹50,00,000 ($60k)
-   **Focus**: Scaling & Ecosystem.
-   **Product**: Full Suite (DB + Auth + Storage + Compute).
-   **Source**:
    -   1,000 Active Apps.
    -   Protocol Fees compounding.
    -   Marketplace commissions (Devs selling templates).

## Milestone 4: ₹50,00,000 -> ₹1,00,00,000 ($120k)
-   **Focus**: Institutional Adoption.
-   **Product**: Enterprise Gateway.
-   **Source**:
    -   Large scale data storage contracts.
    -   SaaS wrapper subscriptions.

## The Math
To hit ₹1Cr/year:
-   Need ~$10k/month MRR.
-   At 5% fee, we need $200k/month in network volume.
-   OR: 500 customers paying $20/month for the "Managed Gateway" convenience layer.
